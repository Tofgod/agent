# 项目目录约定

每个项目独立提供以下八个一级目录。一级目录始终显示，子目录随实际文件出现；新项目不预设集数，不创建示例文档或空子目录。

```text
项目/
├─ 01_创作/    剧本、分镜、角色设定、项目记忆
├─ 02_参考/    用户上传的参考图片、视频和资料
├─ 03_图片/    生成的角色图、场景图、关键帧
├─ 04_视频/    生成的视频镜头、剪辑片段
├─ 05_音频/    配音、音乐、音效
├─ 06_字幕/    字幕文件
├─ 07_成片/    最终视频
└─ 08_记录/    制作进度、审查结果、失败记录
```

AI 保存前先查看现有目录，复用对应文件；需要分集时，可创建 `01_创作/第三集/剧本.md`、`03_图片/第三集/` 等子目录。一次性短片可直接保存为 `01_创作/剧本.md`，没有默认集数。内容使用自由 Markdown，不限定剧本模板或创作阶段。

项目记忆位于 `01_创作/项目记忆.md`。更新同一文档使用版本记录，避免创建“最终版2”“最新版3”。联动修改多份文件可使用 `edit_files`，任一版本、匹配或锁定检查失败时全部不改，提交中发生数据库错误时整体回滚。

上传图片、视频、音频和 Markdown 分别进入 `02_参考/图片/`、`02_参考/视频/`、`02_参考/音频/`、`02_参考/资料/`，保留文件名；这些子目录仅在上传后出现。生成图片必须写入 `03_图片`，视频镜头写入 `04_视频`，合成成片写入 `07_成片`。新增或移动文件必须位于固定一级目录内。

目录定义、归类和路径检查统一位于 `lib/studio/project-layout.ts`，由文件树、AI 工具和上传接口共用。当前是 SQLite 文档与本地媒体文件支撑的项目文件系统，尚未连接任意宿主机目录。文本 ZIP 导出保留八个一级目录，不附加项目参数文档。

按需创建的 `01_创作/指南/` 可保存本项目的工作知识。其 Markdown 会自动加入 AI 知识目录，文件相对路径去掉 `.md` 后作为名称，同名指南优先于内置版本。它们仍是普通可编辑文档；新项目不会预建指南文件或子目录。
