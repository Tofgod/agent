# do漫

对话驱动的动画短剧工作室。智能体通过文件工具自主读取、创作、修改和整理项目，创作文档使用 Markdown；所有文件按项目隔离，子目录按实际内容创建。

## 使用

在模型设置中填写所用服务的 API Key。对话、编剧和导演使用 DeepSeek Flash（`deepseek-flash`）。图片默认使用 AI Club 的 `doubao-seedream-5-5-261028`，请求 `/model/openApi/v1/images/generations`；Seedream 5.0 Pro 仍可使用火山方舟。视频可选 AI Club Seedance 2.5、2.0、2.0 Fast，火山方舟 Seedance 2.0、2.5 或 MiniMax H3、H3 Max。AI Club 图片和视频共用一个 API Key，所有密钥由本地服务加密保存。DeepSeek、火山方舟和 MiniMax 的 API 地址可以在模型设置中修改。

分享项目之前，可以在「模型设置 → 清空已保存的模型密钥」确认清空。服务删除 SQLite 中保存的模型 Key，重建数据库并清理 WAL，同时处理项目下已知运行目录中的旧工作室数据库。项目、对话、素材和其他模型选项会保留。清空仅处理保存于模型设置中的 Key，曾手工写入文档、聊天或另外备份的密钥需单独检查。

AI Club Seedance 使用 `/model/openApi/doubao/v1/video` 提交，通过 `/model/openApi/doubao/v1/tasks/{id}` 查询。支持提示词直出、项目首帧或首尾帧、按模型能力选用的多素材参考。`generate_video` 的 `reference_videos` 可按顺序混填公网 HTTPS 链接（`{"type":"url","url":"…"}`）和项目路径（`{"type":"project_file","path":"…"}`）。公网链接原样提交，项目视频需要已有供应商可访问的地址，项目上传文件保存在本地。旧 `reference_video_paths` 仍可用，与新字段同传时排在其后。取消后停止本地执行并通过查询核对供应商状态，取得视频链接后可继续保存原结果。


新建项目一键进入空白对话，没有填写表单或项目参数设置页。左侧切换项目，中间进行创作对话，右侧查看项目文件。文件目录在右侧预览区内，两个分隔手柄分别调整预览区和目录宽度，并在本机记住设置。目录可单独收起。

固定一级目录为 `01_创作`、`02_参考`、`03_图片`、`04_视频`、`05_音频`、`06_字幕`、`07_成片`、`08_记录`。新项目没有文件或预设集数。子目录随实际保存的文件创建，AI 与上传接口遵守同一目录规则；上传后自动展开至文件。具体约定见 [项目目录](docs/project-files.md)。

AI 完成本次要求的剧本、分镜、设定、提示词等文字内容后，告知结果并结束本轮，等待用户后续指示，再继续图片或视频创作。这是主、子智能体共同遵守的行为要求，不增加关键词识别、程序硬检查或审批流程。

系统提示说明项目目录用途及本轮文字交付约定。创作内容、结构和风格由 AI 根据用户本轮要求决定。动态项目事实由 `runtime-context.ts` 单独提供，项目记忆可按路径和版本读取，协作状态对应当前任务树。

聊天采用 DeepSeek 原生工具调用循环，提供文件读写、项目内搜索、图片和视频生成及合成工具。AI 可以维护 `/01_创作/项目记忆.md`，长执行历史会压缩为持久摘要。创作文档使用自由 Markdown。项目内自行保存的 `01_创作/指南/` 文件可用 `read_guide` 按需读取，目录只提供文件元数据。长文续读携带上一页的 `revision`。单张图片、单个视频和按视频列表合成都可以独立执行。

主智能体可委派编剧、导演或本地注册的角色。每个子任务有独立、可恢复的上下文，协作者共享本项目文件。媒体生成作为独立后台任务运行，调度器为主对话保留独立名额。对话中的项目说明、工具操作和子任务回复直接按事件顺序显示，刷新后可继续阅读。实时状态放在当前内容之后，完成的等待按结算位置进入记录。输入区右下角使用同一个发送和停止按钮，普通回复结束后直接回到聊天。

运行中可直接发送补充要求，也可点「排到下一轮」或按 Alt + Enter。队列按项目保存在 SQLite。待发期间可改正文和素材、撤回，或点发送图标加入当前轮。加入当前轮的消息等正在执行的步骤结束后送达。多条待发消息可以折叠。在对话或输入框连续按两次 Esc，可停止当前执行并保留草稿。

文档使用 `.md`。预览采用 react-markdown 与 remark-gfm，编辑采用 CodeMirror 6 的 Markdown 扩展，支持撤销、重做、查找和 Cmd/Ctrl+S 保存。保存创建新版本，锁定后禁止覆盖。文档内的项目相对图片和视频链接会解析到本项目素材。点击对话中的项目文件链接可打开右侧文件预览。

长文读取提供行和字符续读位置，不会悄悄丢弃长行尾部；目录与搜索结果控制完整返回大小。`edit_files` 先检查整批文件，再事务提交修改与回执，避免剧本和分镜只改成功一半，并保留原文件的 CRLF 换行。

图片、视频、音频及 Markdown 可上传并预览，原始上传归入 `02_参考`。可用视频的原有音轨可保留，用户上传的独立配音可替换对应片段的声音。智能体按用户意图选择片段、顺序、时长、音轨与台词，后台使用 FFmpeg 合成 MP4，烧录指定台词字幕并保存到成片目录。关闭页面后本地服务仍会继续。镜头时长不足、配音超长或有台词却缺少音轨时，合成会返回具体原因。

`read_image` 使用 Sharp 解码项目图片的实际像素，按需生成适合模型请求的副本，并绑定所读文件版本。超出请求预算的较早图片可以从原路径重新读。`read_video` 在后台抽取实际画面，默认 6 帧或指定最多 12 个时间点，同时读取时长、尺寸、帧率和音轨信息。图片保存到 `03_图片/检查/素材名_v版本_检查序号`，父智能体接收参与检查的实际帧。

联网搜索复用 DeepSeek 密钥，直接使用官方 `/v1/tools/search` 与 `/v1/tools/fetch`，模型按需调用 `web_search`、`web_fetch`。请求先登记，结果未知的中断请求不自动再次发送；来源链接、摘要、发布时间和抓取时间保留在工具回执中，长网页可续读而不重复抓取。模型设置中的“联网搜索”可关闭两项工具。聊天支持 Markdown 来源链接。联网服务按供应商规则计费。已用保存的 DeepSeek 配置分别验证官方 Search 和 Fetch，两个 HTTP 200 响应均进入智能体工具回执。网页内容作为外部资料处理，不作为执行指令。

## 开发

### 使用启动脚本

克隆或完整解压项目后，在与 `package.json` 同级的目录运行 `setup.command`。它会检查并补齐 Node.js、npm、FFmpeg 和 ffprobe，安装项目依赖，构建并启动 do漫。以后运行 `start.command` 即可。macOS 可在 Finder 双击；也可在终端运行以下命令。

```sh
bash setup.command
# 以后启动
bash start.command
```

macOS 自动安装使用 [Homebrew](https://brew.sh/)，安装器可能要求确认。Ubuntu、Debian 及基于它们的 Windows WSL 可以用同一组命令，缺少的系统包通过 apt 安装，Node.js 安装到项目本地目录。其他 Linux 发行版可在自行准备依赖后运行脚本。

看到后台已启动后，打开 [http://127.0.0.1:5179](http://127.0.0.1:5179)，在模型设置中填入自己的 API Key。启动窗口保持开启，按 Ctrl+C 可停止。更新源码后可重新运行 `setup.command` 构建最新版。

其他项目占用默认端口时，可运行 `DOMAN_PORT=5180 bash start.command`，然后访问对应端口。

### 手动开发

需要 Node.js >=24.9.0，以及可从 PATH 调用的 FFmpeg / ffprobe。前端为 Vite + React + TypeScript；后端为 Node.js HTTP 服务、原生 SQLite 和本地媒体文件。任务调度和 FFmpeg 在本机后台运行。运行和构建均不依赖 Cloudflare。

```sh
npm run install:ci
npm run dev -- --hostname 127.0.0.1 --port 5179
npm run typecheck
npm test
npm run build
```

`npm run dev` 一起启动页面服务与后台进程，自动生成并保留本地加密密钥、后台通信密钥，自动应用 `drizzle/` 中尚未执行的本地数据库变更。密钥位于忽略提交的 `.env.local`，数据库位于 `data/studio.sqlite`，媒体位于 `data/media`。`STUDIO_DATA_DIR` 可指定独立数据目录；它必须与对应的加密密钥一起备份。不要随意更换加密密钥，否则无法读取已保存的模型密钥。

在数据目录的 `agents.json` 中可增加角色，服务启动时读取。每项使用 `id`、`name` 和可选的 `description`。例如以下配置会加一个剪辑师，主智能体可以自行决定是否委派。

```json
[
  { "id": "editor", "name": "剪辑师", "description": "检查镜头衔接、剪辑节奏与素材" }
]
```

每次新委派创建一个独立实例。同一个角色可以承担多个互相独立的任务。委派名称在同一对话中唯一，主智能体在该对话中一直用 `lead` 寻址。用 `send_message` 和子任务名称或编号，可以跨轮继续已有实例。每轮回复和执行记录仍有自己的运行编号。

单独及批量委派都可以指定工作目录 `cwd`。相对路径从该目录解析，以 `/` 开头的路径从项目根解析。子任务默认继承主对话的 DeepSeek 线路。使用官方连接时，可通过角色的 `textRoute` 或委派的 `provider` 和 `model` 指定该实例的线路，支持 `chat-completions` 和 `messages`，模型均为 `deepseek-flash`。设置随任务保存，复用相同服务的凭据。

需要将数据传给主任务或批次依赖时，可为该任务提供对象型 `output_schema`。子智能体用 `structured_output` 提交，校验成功后结束本轮。主任务用 `wait_for_tasks` 读取结果，批次后续任务也会得到对应数据或可续读的回执。创作文档继续使用自由 Markdown。

长对话压缩按请求实际使用的 API 线路和模型计算。默认触发比例是窗口的 80%，同时扣除生成预留和 65,536 token 压缩余量。默认保留量是可输入预算的 16%。官方 Flash 使用模型声明的 1,048,576 token 窗口。`STUDIO_CONTEXT_WINDOW` 仍可指定部署的默认窗口。收到供应商用量后，用实际输入 token 校准后续请求。达到阈值后先裁剪旧回执，再判断是否需要摘要。供应商明确报超限时跳过本地阈值，缩减已有上下文后自动重试一次。

可在数据目录的 `compaction.json` 里配置规则，由服务启动时读取。`modelPolicies` 按实际请求地址和模型匹配，每条规则覆盖同名默认值。`retainTokens` 和 `retainRatio` 可任选一种。例如下面只调整官方 Messages 线路。摘要输出上限使用 `maxTokens`，普通回复沿用原模型设置。

```json
{
  "modelPolicies": [
    { "baseUrl": "https://api.deepseek.com/anthropic", "model": "deepseek-flash", "thresholdRatio": 0.72, "retainTokens": 24000 }
  ]
}
```

对话空闲时输入 `/compact` 可整理较早上下文，保留原聊天显示和最新一轮。整理期间的新消息按顺序待发。生成中 Enter 的发送方式可以在模型设置调整，Cmd/Ctrl+Enter 使用另一种方式。输入框为空时按 Cmd/Ctrl+Enter，可把待发消息按顺序送进当前轮的下一步。

后台仅监听和连接本机，通过独立令牌认证。临时网络失败最多自动重试三次；不确定是否已提交的付费生成不会自动重提。Seedream 同步返回的图片地址会先持久保存再下载，失败只重试下载。AI Club 返回的 JPEG 会转为 PNG 保存到项目的图片目录。图片和视频任务沿用创建时的模型和 API 地址，视频查询还沿用已保存的供应商任务 ID。模型工具调用在执行前保存，文件写入和工具发出的任务控制分别与对应回执在同一事务提交。应用启动时释放已确认退出的本机服务持有的旧租约，继续未完成的任务。旧版本租约和进程仍存活的租约按原期限处理。

模型 SSE 使用 eventsource-parser 解析，正文大小与协议传输大小分别计量，避免正常长回复被协议开销误判。请求、工具定义、线路及完整响应保存在 `model_calls`。恢复已有工具调用时沿用该步的定义和线路，鉴权凭据仍从当前同源连接读取。每次请求前校验工具组与回执配对。新一轮从前一轮接上已提交的工作，失败的模型尝试单独留在记录里。限流按 `Retry-After` 持久排队，超时和用户打断时可利用已有正文，输出截断时按现有提示缩短回复或分次写入。记录供应商返回的 token 用量和请求编号。

运行时用 SQLite 追加会话状态变更，记录模型请求、回复接纳、工具结果和上下文压缩。当前状态作为读取缓存，缓存缺失时按顺序回放。新指令到达时中断旧响应，保留已交付文字，再处理新输入。编剧、导演和视频检查等委派保留父子等待与控制。图片、视频和合成任务可在聊天轮次结束后继续，可在原消息的任务行暂停、继续或取消。本轮依赖产物时，智能体可以等待任务。取消立即停止该任务的本地执行，再由后台持续核对外部任务。查询排队状态后才请求供应商取消，运行中任务无法取消，已完成任务保留结果地址；无法确认则明确显示未知。查询可跨重启恢复，不触发新的生成提交。可用“获取原结果”继续原任务，暂停只暂停本地推进。同一输出路径由事务占用，正在执行、暂停或提交结果未知的任务会阻止重复生成。全文覆盖需要先读取文件版本，用户编辑或其他智能体产生新版本后，旧上下文不能直接覆盖。

本地启动后直接使用本机工作室，不依赖外部站点登录。项目及媒体归属于本地身份。

## 本地扩展

- 在「扩展 → MCP → 凭据」保存命名凭据。在 HTTP 请求头中可填 `{"Authorization":"Bearer ${credential:NAME}"}`，或在 STDIO 环境变量中填 `${credential:NAME}`。更新命名凭据会重新连接引用它的服务。连接状态实时更新。
- Skills 识别空白分隔的 `/技能名`，写在句中也可补全和调用。本地发现包括项目的 `.dsh/skills`、`.agents/skills` 和 `STUDIO_SKILL_DIRS` 指定的目录。
- 已安装的扩展可在「会话预设 → 扩展组件」中选择。服务启动时从数据目录的 `extensions.mjs` 加载，也可用 `STUDIO_EXTENSIONS_FILE` 指向本机模块。模块导出 `plugins` 数组，成员包含 `id`、`name`、`setup(scope)`。可选的 `host` 数组指定全局加载的组件 ID。组件使用 `registerTool`、`registerSkillProvider` 和 `registerMcp` 提供能力，用 `onDispose` 注册清理。
- 定时任务由后台独立扫描。`STUDIO_NEW_SESSION_INTERVAL_SECONDS` 可设置每次新建对话的最小投递间隔，`STUDIO_SCHEDULE_HISTORY_DAYS` 和 `STUDIO_SCHEDULE_HISTORY_RECORDS` 设置历史保留范围，默认分别为 60 秒、30 天和 200 条。

## 验证与当前边界

核心测试覆盖项目隔离、密钥、文件版本、锁定、任务租约、取消、源文件变更、编剧审查改稿循环、编辑文档传入导演、ZIP 与字幕时序。

已用用户保存的 DeepSeek 密钥验证连接、真实流式文本和主任务委派编剧后等待结果的完整对话。图片、视频付费生成尚未进行真实联调，接口契约测试不能证明动画质量。自动媒体审片、对白与口型核验、背景音乐混音和预算账本仍待实现。

当前文档与版本保存在 SQLite，素材保存在本地文件；AI 操作的是项目目录视图，尚未直接接入用户指定的任意磁盘目录。协作树内的创作智能体可通过 `list_agents`、`send_message` 相互发现和通信，消息与回执一起持久保存，暂停或取消的任务不会被消息自动恢复。真实视频帧的模型效果、费用核算与完整会话事件回放仍待验证或完善。工具执行记录已独立持久保存，不随模型上下文压缩而消失。

接口依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[火山图片生成](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[Seedance 2.0](https://docs.volcengine.com/docs/ark/seedance-2-0?lang=zh)、[Seedance 2.5](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)、[MiniMax H3 视频生成](https://platform.minimax.cn/docs/api-reference/video-generation-v2-create)。

编辑中的文档保留草稿和原始版本号。后台产生新版本时不会直接覆盖用户草稿；保存冲突需要明确选择载入新版本或保留草稿。

`tests/media-check.ts` 是本地手动集成检查，创建专用开发项目和测试图形/视频，不调用付费生成服务。`--background --pause-for-restart` 提交并暂停测试任务；重启本地工作室后用 `--resume` 验证恢复与成片。整个验证不需要打开浏览器，也不调用付费生成。

生产模式先执行 `npm run build`，再执行 `npm start -- --hostname 127.0.0.1 --port 5179`。构建只产生 `dist/client` 和 `dist/server/index.mjs`，无需外部托管服务。

134 项自动测试覆盖真实 SQLite 事务、媒体不可变版本及分段读取、主子任务回执配对、执行记录持久化与分页、长流式响应及截断恢复。另在真实本地 HTTP 服务中验证抽取 3 帧、带音轨合成和 15 秒中文字幕测试成片；测试图形不能代表 AI 动画质量。

用户消息右下方悬停显示发送时间与复制图标，气泡下方整条操作区域均可触发；复制保留原文并短暂显示成功图标。键盘聚焦时显示，触屏设备直接提供操作。气泡采用较圆润的边角和轻描边。


### 本机项目目录和后台任务

文件区右上角的文件夹按钮打开该项目的本机目录，默认位于 `data/workspaces/<项目ID>`。从文件区也能直接新建 Markdown、重命名或删除文件。本机目录里的 Markdown 和支持的图片、视频、音频变更同步到项目版本记录。若界面和本机同时修改同一份文件，本机内容保留为独立副本。

进行中的后台任务可以展开查看输出。任务结束后在原对话的任务行查看输出。智能体可用 `job_output` 立即读取增量和最终结果，确实需要等待时传 `wait: true`。

| 可选本地配置 | 默认值 |
| --- | --- |
| `STUDIO_MAX_DELEGATION_DEPTH` | `1`，设为 `2` 时允许子智能体再委派一层 |
| `STUDIO_JOB_WAIT_TIMEOUT_MS` | `30000` |
| `STUDIO_JOB_MAX_WAIT_TIMEOUT_MS` | `600000` |
| `STUDIO_JOB_COMPLETION_DELIVERY` | `wakeup`，可选 `quiet` |
| `STUDIO_MAX_CONSECUTIVE_WAKES` | 无上限，可设为正整数，处理新用户输入后重置 |
